# Security policy

Autopilot launches AI agents that run commands on your machine, so safety bugs matter. Examples: a way around the deny list, a way to merge or publish, or a human gate that can be skipped.

Please **don't open a public issue** for these. Report them privately via **Security → Report a vulnerability** on this repository. Include steps to reproduce and the versions of `dev-autopilot`, `claude` and `codex` you used.

Only the latest release receives fixes.
